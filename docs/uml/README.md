# UML Diagram Sources

This directory contains PlantUML source diagrams for the firmware architecture.

## Files

- `component-overview.puml` - high-level runtime/system components
- `module-class-diagram.puml` - core module class relationships
- `bitchat-bridge-sequence.puml` - BitChat bridge data flow sequence

## Rendering

If you have PlantUML installed locally:

```bash
plantuml docs/uml/component-overview.puml
plantuml docs/uml/module-class-diagram.puml
plantuml docs/uml/bitchat-bridge-sequence.puml
```

Generated images are not committed by default.
